### 💡 왜 마우스 커서가 앱 영역 내부에서만 스크롤이 되고, 윈도우 배경 창에서는 반응하지 않았는가?

#### 1. 웹 브라우저의 마우스 휠 이벤트(`wheel event`) 전달 구조
웹 브라우저는 마우스 휠을 굴릴 때 **마우스 커서가 위치한 정확한 DOM 요소(`event.target`)** 로 스크롤 이벤트를 전달합니다.

#### 2. 현재 앱 레이아웃 구조의 문제 원인
* **App.tsx 컨테이너 구조**:
  * 바깥 배경(`outerBackground`): `height: 100%`로 고정 (스크롤 안 됨)

  * 각 화면 내부(`HomeScreen`, `CommissionScreen` 등): 내부 `<ScrollView>` div (`overflow-y: auto`)

* **현상 분석**:
  * **마우스 커서가 중앙 앱 프레임(480px) 안**에 있을 때: 이벤트 타겟이 내부 `<ScrollView>` div이므로 앱 내부만 휠 스크롤이 정상 작동합니다.
  * **마우스 커서가 앱 밖의 윈도우 회색 배경**에 있을 때: 이벤트 타겟이 스크롤이 금지된 `outerBackground` 또는 `body` 요소가 되기 때문에, 마우스 휠을 굴려도 아무런 스크롤 반응이 일어나지 않습니다.

- `URL.createObjectURL(file)` → Blob URL 생성 → 브라우저 세션 메모리에만 존재
- 강제 새로고침 시 메모리 초기화 → Blob URL 파괴 → localStorage에 주소는 있지만 실제 데이터 없음 → 이미지 표시 불가

**이번 올바른 방식**:
- `FileReader.readAsDataURL(file)` → Base64 문자열(`data:image/png;base64,...`) 생성
- Base64는 **순수 텍스트**이므로 localStorage에 완벽하게 저장되고 새로고침 후에도 100% 복원됨

---

## 2. 🔍 가시성 (Visibility)

| 구분 | 잘못된 방식(Blob URL) | 올바른 방식(Base64) |
| :--- | :--- | :--- |
| **저장 형태** | `blob:http://localhost/xxxx` (세션 임시 포인터) | `data:image/png;base64,iVBOR...` (실제 이미지 데이터) |
| **새로고침 후** | ❌ Blob 파괴 → 이미지 소멸 | ✅ Base64 문자열 복원 → 이미지 완벽 유지 |
| **저장 위치** | 브라우저 메모리(세션 종료 시 소멸) | localStorage(반영구 저장) |

---

## 3. ⚡ 효율성 (Efficiency)

* 외부 라이브러리 설치 **0건** — 브라우저 내장 `FileReader` API 사용
* Base64 변환은 비동기(`onload` 콜백) 처리로 UI 블로킹 없음
* 변환 즉시 preview 표시 및 저장 모달 호출 — 사용자 대기 시간 없음

---

## 4. 🎁 기대 효과 (Effects & Benefits)

* 프로필 사진을 한 번 등록하면 **강제 새로고침, 탭 이동, 앱 재진입 어떤 상황에서도 사진이 사라지지 않음**
* 추후 백엔드 연동 시 Base64를 서버 API로 전송하거나 URL로 교체하는 확장 구조 유연하게 설계

### 1) [DrawerMenuScreen.tsx](file:///c:/Users/saman/Desktop/trend_force_app/src/screens/DrawerMenuScreen.tsx)
* **콜백 프로퍼티 추가 (`DrawerMenuScreenProps`)**:
  ```tsx
  interface DrawerMenuScreenProps {
    onClose: () => void;
    onNavigateToProfile?: () => void;          // 공정 1: 프로필 관리 이동
    onNavigateToInviteRegister?: () => void;   // 공정 2: 초대 코드 등록 이동
    onNavigateToOrganization?: () => void;     // 공정 3: 조직 관리 이동
  }
  ```
* **상단 헤더 버튼 클릭 이벤트 핸들러 연동 (공정 1)**:
  ```tsx
  {/* 상단 프로필 전체 버튼 클릭 시 프로필 관리 화면으로 전환 */}

    style={styles.userHeaderRow} 
    activeOpacity={0.7}
    onPress={() => {
      onClose();
      onNavigateToProfile?.();
    }}
  >
    <View style={styles.userInfoLeft}>
      <Text style={styles.userNameText}>{MOCK_USER_PROFILE.name}님</Text>
      <View style={styles.appointedBadge}>
        <Text style={styles.appointedBadgeText}>위촉회원</Text>
      </View>
    </View>
    <Text style={styles.chevronIcon}>›</Text>
  </TouchableOpacity>
  ```
* **초대 코드 등록 / 조직 관리 버튼 연동 (공정 2, 3)**:
  ```tsx
  <TouchableOpacity
  ```
